# Fiche à remplir pour un essai

Copier cette fiche pour chaque essai. Tu peux me retourner la fiche avec les fichiers correspondants.

- Test : T0 / T1 / T2 / T3 / T4 / T5 / T6
- Date et identifiant de session :
- Ce que je cherche à vérifier :
- Page ou commande utilisée :
- Modèle effectivement chargé (si inconnu, écrire « inconnu ») :
- CPU ou GPU / précision numérique :
- Langue : automatique / forcée (laquelle ?) :
- Prompt / débruitage / VAD / diarisation :
- Fichier audio et durée :
- Qui parle (identifiants stables, pas nécessairement les noms réels) :
- Type de bruit / microphone / chemin audio Teams si applicable :
- Texte exact réellement prononcé et vérifié à l'écoute :
- Texte exact renvoyé par le système, sans correction :
- Temps mesuré et manière de le mesurer (ou « non mesuré ») :
- Résultat : texte reçu / texte absent / erreur / autre :
- Comportement observé :
- Fichiers joints : audio, référence, export, log, vidéo :

Une valeur inconnue reste inconnue. Ne pas écrire 0 comme durée si elle n'a pas été mesurée. Conserver les échecs aussi.
